# Nur Ajanda — 35 sn Reels Reklam Filmi

**Dosya:** `video/out/nur-ajanda-reels-35s.mp4` · 1080×1920 (9:16) · 30 fps · tam 35,00 sn (1050 kare) · H.264 High / yuv420p · AAC 48 kHz stereo
**Kaynak:** `video/src/` (Remotion 4) · Müzik: `video/tools/make_music.py` (özgün, sentez)

## Art direction

- **Konsept:** "Kurumsal ajandada markanızın imzası." — web sitesi konseptiyle aynı görsel dil: ivory kağıt zemin, defter çizgileri ve kırmızı kenar çizgisi (ajanda sayfası motifi), mürekkep siyahı, logo kırmızısı yalnızca aksan.
- **Tipografi:** Instrument Serif (başlıklar, editoryal italik vurgu) + Manrope (bilgi/etiket). İkisi de OFL lisanslı.
- **Hareket:** Maskeli tipografi (satır satır yukarı kayma), sahne geçişlerinde maske/wipe (kırmızı kenar çizgisiyle), 2.5D ürün katmanları (yay/spring fiziği, farklı hızlarda kayan katmanlar), gofre kabartması üzerinde ışık süpürmesi, yavaş kamera yaklaşması, hafif film greni ve vinyet.
- **Ürünler:** Tüm görseller nurajanda.com'daki gerçek ürün fotoğrafları; yalnızca beyaz stüdyo fonu şeffaflaştırıldı.
- **Güvenli alan:** Tüm yazılar Reels arayüzünün kapladığı üst ~250 px ve alt ~380 px dışında (x: 86–994 px, y: 170–1540 px).

## Müzik ve ses

- **Özgün sentez müzik** (`make_music.py`): 120 BPM yarım-tempo hissi, Do majör/La minör; sıcak pad, keçe tokmaklı mallet arpeji, yumuşak bas, hafif kick/rim/shaker, stereo konvolüsyon reverb. Hiçbir örnek (sample) veya üçüncü taraf kayıt yoktur → lisans kısıtı yok.
- **Kurguyla senkron:** 0 sn'de açılış vuruşu, 5/11/17/23/29 sn kesmelerine yükselen swell'ler, 29 sn'de logo vuruşu, 35,0 sn'de tam sessizlik.
- **Seviye:** −14,0 LUFS entegre (Instagram referansı), tepe −3,3 dBFS.
- **Seslendirme:** Bu ortamda doğal Türkçe TTS aracı olmadığı için seslendirme eklenmedi; mesaj ekran yazılarıyla taşınıyor. Seslendirme eklenecekse önerilen metin (sakin tempo, ~55 kelime):
  > "Markanız, yıl boyu masada. Tarihli ajandalar, tarihsiz defterler, organizerler… Logonuz; gofre, UV, lazer ya da serigrafiyle, ürünün kendisi kadar özenle. Kalem, masa ve hediyelik setlerle kurumsal hediyede tek adres. Nur Ajanda — teklif listenizi oluşturun: nurajanda.com"

## Yeniden üretim

```bash
cd video
npm install
python3 tools/make_music.py public/audio/nur-ajanda-score.wav   # müziği yeniden üretir (numpy + scipy)
npm run studio     # Remotion Studio'da düzenleme
npm run render     # out/nur-ajanda-reels-35s.mp4
```
Başka bir makinede Chrome yolu farklıysa: `REMOTION_BROWSER=/path/to/chrome npm run render` (ya da değişkeni boş bırakın, Remotion kendi tarayıcısını indirir).
